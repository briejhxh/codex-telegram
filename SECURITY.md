# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not include Telegram API credentials, login codes, session files, database files, private message content, or a real phone number in a public issue.

Use GitHub's private vulnerability-reporting feature for this repository when it is enabled. Otherwise, contact the maintainer through the repository owner profile with a minimal reproduction and a redacted description. Include affected version, impact, and safe reproduction steps.

## Scope

In scope: credential and session handling, filesystem access, TDLib/MCP boundaries, message-send and inline-button controls, dependency vulnerabilities, and secret exposure in the repository.

Out of scope: Telegram service availability, compromised local machines, or social engineering using a user's own Telegram account.
